# AWS S3 Static Website Hosting

## Project Overview
This project demonstrates hosting a static website using Amazon S3.

## AWS Services Used
- Amazon S3
- Static Website Hosting
- Bucket Policy

## Architecture
User → Internet → Amazon S3 → Static Website Hosting

## Steps
1. Created S3 bucket
2. Uploaded index.html
3. Enabled static website hosting
4. Configured bucket policy for public access
